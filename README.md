This folder contains all the codes of my work. The information rate calculation code is in the [info_geo_plos] folder. The [preprocessing] folder contains the codes of converting the raw data (from https://misp.mui.ac.ir/en/eeg-data-0) to bids format and the preprocessing of the signals. 

The first dataset can be obtained from OpenNeuro via [https://openneuro.org/datasets/ds004504/versions/1.0.7], the second dataset can be obtained via [https://misp.mui.ac.ir/en/eeg-data-0].
