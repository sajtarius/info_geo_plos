This folder contains all the codes of my work. The information rate calculation code is located in the [info_geo_plos] folder. The [preprocessing] folder includes the code for converting the raw data (available at https://misp.mui.ac.ir/en/eeg-data-0) into bids format, as well as for preprocessing the signals. 

The first dataset can be obtained from OpenNeuro at [https://openneuro.org/datasets/ds004504/versions/1.0.7], and the second dataset is available at [https://misp.mui.ac.ir/en/eeg-data-0]. Notably, the first dataset already contains the preprocessed data in [derivatives] folder; therefore, no additional preprocessing is required for it.
